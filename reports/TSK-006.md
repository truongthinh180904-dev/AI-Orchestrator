# Báo cáo nghiệm thu TSK-006: API POST /import (dry-run + commit), GET/PATCH /tasks, GET /features — Test API (inject Fastify)

## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ**: Xây dựng toàn bộ hệ thống API cốt lõi của orchestrator trên nền tảng Fastify và TypeScript:
  - `POST /import`: Chế độ `dry-run` (kiểm tra toàn diện, trả về báo cáo lỗi/cảnh báo mà không lưu) và chế độ `commit` (thực thi ghi toàn bộ features, tasks và dependencies vào SQLite trong một transaction nguyên tử).
  - `GET /tasks`: Truy vấn danh sách tasks kèm quan hệ phụ thuộc (`dependencies`), hỗ trợ lọc theo `status`, `feature_id`, `phase` và tìm kiếm từ khóa `search`.
  - `GET /tasks/:id`: Lấy chi tiết một task theo mã định danh.
  - `PATCH /tasks/:id` & `PATCH /tasks`: Cập nhật linh hoạt các thuộc tính task (trạng thái, ưu tiên, tiêu chí nghiệm thu, v.v.), kiểm soát chặt chẽ quan hệ phụ thuộc không tồn tại hoặc gây chu trình.
  - `GET /features` & `GET /features/:id`: Truy vấn danh sách và chi tiết các features, hỗ trợ lọc theo trạng thái.
  - `GET /health`: Kiểm tra trạng thái máy chủ.
  - Quản lý lỗi tập trung qua `AppError` và `ZodError` trả về JSON cấu trúc chuẩn `{ error: { code, message, context } }`.
- **Tiêu chí nghiệm thu theo ROADMAP.md**: `Test API (inject Fastify)`.
