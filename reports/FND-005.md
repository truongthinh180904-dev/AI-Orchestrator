# Báo cáo Nghiệm thu FND-005

## Thông tin Task
- **ID**: `FND-005`
- **Mô tả**: Load env bằng zod, `.env.example`, `.gitignore` chặn `.env`
- **Dependency**: `FND-001` (đã hoàn thành)
- **Tiêu chuẩn nghiệm thu**: Thiếu biến bắt buộc → báo lỗi rõ; không secret trong git

## Các thành phần đã triển khai

1. **Schema & Environment Loader (`packages/shared/src/env.ts`)**:
   - Sử dụng thư viện `zod` xác thực dữ liệu đầu vào theo quy chuẩn monorepo.
   - Định nghĩa `envSchema` bao gồm:
     - `DATABASE_PATH`: Biến bắt buộc (`min(1)`), chỉ định đường dẫn file SQLite.
     - `NODE_ENV`: Enum `'development' | 'test' | 'production'`, mặc định `'development'`.
     - `PORT`: Coerce sang số nguyên trong khoảng `1 - 65535`, mặc định `3000`.
     - `HOST`: Chuỗi địa chỉ host, mặc định `'127.0.0.1'`.
     - `LOG_LEVEL`: Enum `'debug' | 'info' | 'warn' | 'error'`, mặc định `'info'`.
     - `AGY_BIN`: Đường dẫn/tên executable AGY worker, mặc định `'agy'`.
     - `AGY_ARGS`: Tham số CLI tùy chọn.
     - `NEXT_PUBLIC_ORCH_URL`: URL API cho Dashboard, tùy chọn.
   - Hàm `validateEnv(raw, schema)`: Xác thực dictionary biến môi trường. Khi thiếu biến bắt buộc hoặc sai định dạng, ném `AppError` với mã `ENV_VALIDATION_ERROR`, thông báo chi tiết từng trường lỗi (`[FIELD] message`), kèm mảng `issues` trong `context`.
   - Hàm `parseEnv(content)`: Trích xuất biến môi trường từ chuỗi NDJSON/dotenv, hỗ trợ dòng chú thích `#`, khoảng trắng, giá trị đóng mở ngoặc kép/đơn và prefix `export`.
   - Hàm `loadEnvFile(filePath)`: Đọc và parse file env; ném `AppError('ENV_FILE_NOT_FOUND', ...)` nếu file không tồn tại.
   - Hàm `loadEnv(options)`: Nạp cấu hình từ file `.env` hoặc tham số chỉ định, hỗ trợ cập nhật an toàn vào `process.env`.
   - Re-export toàn bộ module qua `packages/shared/src/index.ts`.

2. **Cấu hình Orchestrator (`apps/orchestrator`)**:
   - Khai báo dependency `@ai-orchestrator/shared: "workspace:*"`.
   - Bổ sung module `apps/orchestrator/src/config.ts` cung cấp hàm `getOrchestratorConfig()` phục vụ khởi chạy dịch vụ.

3. **Mẫu cấu hình `.env.example` & Chặn Secret qua `.gitignore`**:
   - Tạo file `.env.example` tại thư mục gốc chứa các biến mẫu tiêu chuẩn kèm ghi chú hướng dẫn, không chứa bất kỳ secret hay credential thật nào.
   - Cấu hình `.gitignore` chặn `.env` và mọi file `.env.*`, chỉ ngoại lệ cho phép theo dõi `!.env.example`.
   - Xác nhận qua `git check-ignore` và `git ls-files` không có file `.env` chứa bí mật nào bị theo dõi bởi Git.

4. **Kiểm thử tự động**:
   - `packages/shared/src/__tests__/env.test.ts` (11 tests): Kiểm tra toàn diện schema Zod, validation biến bắt buộc, gán default, coerce PORT, parse cú pháp env file và xử lý ngoại lệ file.
   - `test/fnd-005.test.ts` (9 tests): Kiểm thử tích hợp tiêu chí nghiệm thu cấp độ root:
     - Nghiệm thu 1: Thiếu biến bắt buộc (`DATABASE_PATH`) hoặc biến rỗng/sai kiểu ném lỗi rõ ràng (`AppError` `ENV_VALIDATION_ERROR`).
     - Nghiệm thu 2: `.gitignore` chặn `.env` và `.env.*`; `.gitignore` không chặn `.env.example`; không có file `.env` nào bị Git theo dõi; `.env.example` không chứa secret thật.
     - Tích hợp module `apps/orchestrator`.
