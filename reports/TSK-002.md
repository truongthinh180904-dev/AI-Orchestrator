# Báo cáo nghiệm thu TSK-002: Parser Excel/CSV (exceljs/papaparse) theo 3 sheet: Tasks, Features, Config

## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ**: Xây dựng module parser Excel (`exceljs`) và CSV (`papaparse`) bóc tách dữ liệu theo 3 sheet: `Tasks`, `Features`, `Config` với khả năng chuẩn hóa dữ liệu, nhận diện alias tiêu đề cột (tiếng Anh/Việt) và hỗ trợ nạp từ nhiều nguồn (đường dẫn file, Buffer, thư mục CSV, đối tượng).

## 3. Bằng chứng nghiệm thu chi tiết

### Tiêu chí: Đọc đúng file mẫu
- **Mô tả**:
  1. Module đọc đúng file mẫu Excel (`fixtures/sample-tasks.xlsx`) với đầy đủ 3 sheet `Tasks`, `Features`, `Config`. Bóc tách chính xác từng trường của task (`id`, `feature_id`, `title`, `description`, `phase`, `worker_type`, `repository`, `acceptance_criteria`, `test_commands`, `priority`, `max_attempts`, `timeout_minutes`, `dependencies`, `status`), feature (`id`, `name`, `description`, `required_tasks`, `integration_tests`, `release_policy`, `status`), và config (`repository`, `agy_bin`, `agy_args`, `verify_commands`, `max_attempts`, `timeout_minutes`, `max_concurrency`).
