## 1. Kết Quả Thực Hiện

### 1.1. Migration 007 & Schema Cột `scope_files` (`packages/db/migrations/007_task_scope_files.sql`)
- Mở rộng bảng `tasks` với cột JSON `scope_files TEXT NOT NULL DEFAULT '[]'`.
- Đồng bộ `TaskSchema`, `CreateTaskInputSchema`, `UpdateTaskInputSchema` trong `@ai-orchestrator/shared`.
- Tự động parse và serialize `scope_files` qua Zod trong `TaskRepository` (`rowToTask`, `create`, `update`).
- Cập nhật `PlanOrchestrator.materializePlanTasks` để tự động truyền `scope_files` từ các task trong Plan đã duyệt sang bảng `tasks`.

### 1.2. Mô Hình & Giải Thuật Kiểm Tra Phạm Vi (`packages/shared/src/models/quality-scope.ts`)
- **`normalizeScopePath`**: Chuẩn hóa đường dẫn tập tin nhất quán giữa các hệ điều hành (POSIX / Windows, loại bỏ `./`, `/` thừa).
- **`isPathInScope`**: Khớp đường dẫn theo 3 mức độ linh hoạt:
  1. *Khớp chính xác*: `src/models/task.ts`.
  2. *Tiền tố thư mục*: `packages/db/` hoặc `src`.
  3. *Mẫu wildcard / glob*: `*` (trong 1 cấp thư mục) và `**` (đệ quy qua nhiều cấp thư mục, vd: `packages/**/__tests__/*.test.ts`).
- **`evaluateScopeCompliance`**: Phân loại danh sách tập tin thay đổi thành `inScopeFiles` và `outOfScopeFiles` ("file lạ"), tính toán tổng số thay đổi, số dòng thêm/xóa và xác định cờ boolean `isScopeClean`.
- **`parseUnifiedDiff`**: Phân tích cú pháp unified git diff thành các bản ghi chi tiết từng file (`FileDiffDetail`) gồm `path`, `oldPath`, `status` (`added`, `modified`, `deleted`, `renamed`, `untracked`), `additions`, `deletions`, `patch`, `inScope`.

### 1.3. Trích Xuất Git Diff & Untracked Files (`packages/shared/src/git.ts`)
- Mở rộng `getGitDiff(repoPath, options)`:
  - Chạy `git diff` an toàn qua `spawn` (không dùng shell động), hỗ trợ `baseRef`, `targetRef`, `staged`.
  - Kết hợp phân tích `git status --porcelain` để bắt các tập tin untracked (`??`), tạo patch tổng hợp giả lập để không bỏ sót file lạ mới tạo trong quá trình coding của AI.

### 1.4. Dịch Vụ `ScopeDiffService` (`apps/orchestrator/src/services/scope-diff-service.ts`)
- **`resolveTaskScope(taskId)`**:
  - Tra cứu task từ SQLite.
  - Phân giải `scope_files` từ task, tự động fallback sang `plan.tasks` nếu task liên kết với `plan_id`.
  - Phân giải thư mục kho lưu trữ (tích hợp `RepositoryRegistry`).
- **`compareScope(input)`**:
  - Đối chiếu diff thực tế của repository với tập file cho phép.
  - Tự động lưu bản ghi kiểm toán `scope_diff` vào bảng `reports` trong SQLite khi có `runId`.
- **`checkTaskScope(taskId, options)`**:
  - Hàm trợ năng kiểm tra nhanh phạm vi của task.
- **`getTaskDiff(taskId, options)`**:
  - Cung cấp raw patch và danh sách thay đổi có gắn nhãn `inScope` phục vụ Diff Viewer UI (UI-005).

### 1.5. REST API Endpoints (`apps/orchestrator/src/routes/quality.ts`)
- `POST /api/quality/scope-diff`: Nhận `repoPath`, `scopeFiles` tùy chỉnh hoặc `taskId`, trả về `ScopeDiffResult`.
- `GET /api/tasks/:id/scope-diff`: Tự động đối chiếu diff của repository với `scope_files` của task trong DB.
- `GET /api/tasks/:id/diff`: Cung cấp thông tin diff chi tiết và thống kê cho UI Diff Viewer.
