## 1. Kết Quả Thực Hiện

### 1.1. Cấu Hình Service Launchd Plist (`services/launchd/`, `templates/launchd/`)
- Cung cấp sẵn các file cấu hình LaunchAgent XML tuân thủ nghiêm ngặt Apple Property List DTD 1.0:
  - `services/launchd/com.ai-orchestrator.service.plist`:
    - Khởi chạy Orchestrator API server (Fastify daemon) được bọc ngoài bởi `/usr/bin/caffeinate -dimsu`.
    - Thiết lập `KeepAlive: { Crashed: true, SuccessfulExit: false }` để tự hồi phục khi sập đột ngột nhưng không lặp vô tận khi chủ động tắt.
    - Cấu hình `ThrottleInterval: 30` chống crash loop làm kiệt quệ tài nguyên.
    - Ghi nhật ký vào `logs/launchd.service.stdout.log` và `logs/launchd.service.stderr.log`.
    - Đặt `RunAtLoad: true` để khởi động cùng phiên đăng nhập người dùng.
  - `services/launchd/com.ai-orchestrator.runner.plist`:
    - Dành cho runner batch chạy xuyên đêm qua `run-agy.sh`.
    - Thiết lập `StartCalendarInterval` định kỳ (ví dụ 22:00) hoặc tùy chỉnh.
  - `templates/launchd/`: Cung cấp các template có tham số hóa (`{{WORKING_DIR}}`, `{{CAFFEINATE_BIN}}`, `{{PATH}}`, v.v.) để người dùng tùy biến linh hoạt.

### 1.2. Mô Hình Schema Zod & Trình Tạo XML Plist (`packages/shared/src/launchd/`)
- Định nghĩa schema Zod xác thực toàn diện:
  - `LaunchdServiceConfigSchema`: Kiểm định `label`, `programArguments`, `workingDirectory`, `environmentVariables`, `standardOutPath`, `standardErrorPath`, `keepAlive`, `runAtLoad`, `processType`, `nice`, `startInterval`, `startCalendarInterval`, `throttleInterval`.
  - `LaunchdKeepAliveSchema`, `LaunchdProcessTypeSchema`, `LaunchdCalendarIntervalSchema`.
- `generateLaunchdPlist(config)`: Sinh định dạng XML Apple plist chuẩn chỉnh, tự động escape an toàn các ký tự XML đặc biệt (`&`, `<`, `>`, `"`, `'`).
- `validatePlistXml(xml)`: Kiểm tra cấu trúc thẻ XML, sự cân bằng giữa thẻ mở/đóng và các khóa bắt buộc (`Label`, `ProgramArguments`).

### 1.3. Quản Lý Tiện Ích Chống Ngủ Caffeinate (`packages/shared/src/power/`, `apps/orchestrator/src/services/caffeinate-manager.ts`)
- Schema `PowerAssertionConfigSchema` và `PowerAssertionStateSchema`.
- Chuyển đổi chính xác 5 cờ năng lượng macOS:
  - `display` -> `-d` (chống tắt màn hình)
  - `idle` -> `-i` (chống sleep khi không có thao tác)
  - `disk` -> `-m` (chống sleep ổ đĩa SSD)
  - `system` -> `-s` (chống sleep hệ điều hành khi cắm sạc AC)
  - `user` -> `-u` (giả lập hoạt động người dùng)
  - Hỗ trợ timeout (`-t <seconds>`) và wait pid (`-w <pid>`).
- Triển khai `CaffeinateManager`:
  - `acquire(config)`: Kích hoạt tiến trình `/usr/bin/caffeinate` nền, theo dõi PID và trạng thái. Chống spawn trùng lặp khi đã active.
  - `release()`: Gửi tín hiệu `SIGTERM` dọn dẹp sạch sẽ, giải phóng assertion.
  - Tự động phát hiện khi process con thoát đột ngột và dọn dẹp trạng thái.
  - Tự động đăng ký hook dọn dẹp khi process chính tắt (`exit`, `SIGINT`, `SIGTERM`).
  - Hỗ trợ chế độ mô phỏng an toàn (simulation) trên các hệ điều hành không phải macOS.

### 1.4. Bộ Kịch Bản Vận Hành & Điều Khiển Dịch Vụ (`scripts/`)
- `scripts/run-caffeinated.sh`:
  - Shell wrapper thực thi bất kỳ lệnh nào dưới sự bảo vệ của `caffeinate -dimsu`.
  - Tự động kiểm tra macOS; trên các OS khác tự động chạy thẳng lệnh không gây lỗi.
- `scripts/service-control.sh`:
  - Trình quản trị LaunchAgent toàn diện hỗ trợ các tác vụ:
    - `install [service|runner]`: Kiểm tra tính hợp lệ qua `plutil -lint`, copy plist vào `~/Library/LaunchAgents/` và đăng ký với `launchctl bootstrap gui/$(id -u)` (hoặc `launchctl load`).
    - `uninstall [service|runner]`: Gỡ bỏ đăng ký (`bootout`) và xóa file plist.
    - `start [service|runner]`: Kích hoạt/kickstart service.
    - `stop [service|runner]`: Gửi tín hiệu dừng `SIGTERM`.
    - `restart [service|runner]`: Dừng và khởi động lại.
    - `status [service|runner]`: Tra cứu trạng thái từ `launchctl`, hiển thị PID và tail log.
    - `logs [service|runner]`: Đọc log stdout/stderr.
    - `generate [service|runner]`: In nội dung plist mẫu.

### 1.5. REST API Quản Trị Power & Launchd (`apps/orchestrator/src/routes/power.ts`)
- `GET /system/power` & `GET /api/system/power`: Lấy snapshot trạng thái power assertion, PID, flags và platform.
- `POST /system/power/assert` & `POST /api/system/power/assert`: Kích hoạt power assertion động qua REST API.
- `POST /system/power/release` & `POST /api/system/power/release`: Giải phóng power assertion.
- `POST /system/launchd/generate-plist` & `POST /api/system/launchd/generate-plist`: Sinh file XML plist trực tuyến từ payload JSON.

### 1.6. Tài Liệu Vận Hành Toàn Diện (`docs/launchd-service-guide.md`, `RUN.md`)
- `docs/launchd-service-guide.md`:
  - Phân tích chi tiết LaunchAgent vs LaunchDaemon.
  - Giải thích cấu trúc từng trường trong file plist.
  - Hướng dẫn cơ chế hoạt động của `caffeinate` và các khuyến nghị phần cứng MacBook (cắm sạc AC, clamshell mode, Display sleep).
  - Hướng dẫn vận hành với `scripts/service-control.sh` và lệnh native `launchctl`.
  - Hướng dẫn tích hợp với OPS-002, OPS-003, OPS-004, OPS-005.
  - Hướng dẫn xử lý sự cố (Troubleshooting): Background Items permissions, biến môi trường PATH, kiểm tra log.
- `RUN.md`: Cập nhật hướng dẫn chạy xuyên đêm bằng Launchd Service.
