# Báo cáo nghiệm thu UI-005: Diff viewer — Xem diff thật

## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ theo ROADMAP.md**:
  - `UI-005`: Diff viewer
  - **Dependencies**: `QLT-003` (DONE)
  - **Tiêu chí nghiệm thu**: `Xem diff thật`
- **Các thành phần đã triển khai**:
  1. **Mô hình dữ liệu và hàm phân tích patch trong `@ai-orchestrator/shared`**:
     - `TaskDiffData` & `TaskDiffDataSchema`: Kiểu dữ liệu chuẩn hóa cho API diff gồm `taskId`, `repoPath`, `scopeFiles`, `isScopeClean`, `outOfScopeFiles`, `changedFiles`, `fileDiffs`, `rawDiff`, `stats`.
     - `parsePatchLines`: Hàm thuần phân tích chuỗi unified git patch thành các dòng cấu trúc (`add`, `delete`, `chunk`, `header`, `context`) kèm theo số dòng cũ/mới chính xác để phục vụ hiển thị code diff.
     - `CompareScopeInput`: Mở rộng kiểu input linh hoạt cho endpoint `/api/quality/scope-diff`.
  2. **API Client (`apps/dashboard/src/lib/api.ts`)**:
     - `getTaskDiff(id, options)`: Gọi `GET /api/tasks/:id/diff`, trả về diff thực tế từ git repository.
     - `getTaskScopeDiff(id, options)`: Gọi `GET /api/tasks/:id/scope-diff`, kiểm tra tính hợp lệ phạm vi task theo QLT-003.
     - `compareScopeDiff(input)`: Gọi `POST /api/quality/scope-diff`, đối chiếu diff tùy chỉnh qua REST API.
  3. **Component `DiffViewer` (`apps/dashboard/src/components/DiffViewer.tsx`)**:
     - Giao diện trực quan chuyên dụng để xem và kiểm tra mã nguồn thay đổi của worker AI.
     - Thanh thống kê (`diff-summary-stats`): Hiển thị mã task, đường dẫn repo, tổng số file thay đổi, số dòng thêm (`+` xanh lá), số dòng xóa (`-` đỏ), nút làm mới (`diff-refresh-btn`).
     - Banner cảnh báo phạm vi Quality Gate QLT-003 (`diff-scope-banner`):
       - Khi sạch phạm vi: Thông báo hợp lệ màu xanh lá `✅ Phạm vi hợp lệ: Tất cả các tập tin sửa đổi đều nằm trong phạm vi cho phép của tác vụ`.
       - Khi có file lạ ngoài scope: Banner cảnh báo `⚠️ Cảnh báo Quality Gate (QLT-003): Phát hiện N tập tin ngoài phạm vi (file lạ)` kèm danh sách file lạ dạng pill (`diff-scope-alien-files`).
     - Bộ điều khiển & Lọc (`diff-controls-bar`):
       - Ô tìm kiếm lọc theo tên hoặc đường dẫn file (`diff-search-input`).
       - Bộ lọc theo scope: Tất cả (`diff-filter-all`), Trong scope (`diff-filter-in-scope`), File lạ (`diff-filter-out-of-scope`).
       - Chuyển đổi chế độ xem: Từng file (`diff-view-files`) vs Raw unified (`diff-view-raw`).
       - Thu gọn/Mở rộng tất cả file (`diff-toggle-collapse-all`).
       - Nút sao chép toàn bộ patch (`diff-copy-all-btn`).
     - Hiển thị từng file dạng Accordion Card:
       - Header: Huy hiệu trạng thái file (`MODIFIED`, `ADDED`, `DELETED`, `RENAMED`, `UNTRACKED`), huy hiệu phạm vi (`Trong scope` vs `⚠️ File lạ`), đường dẫn file, số dòng `+X` / `-Y`, nút sao chép patch của file đó.
       - Body: Bảng unified diff với số dòng cũ, số dòng mới, ký hiệu (+/-/@), tô màu xanh cho dòng thêm (`diff-line-added`), đỏ cho dòng xóa (`diff-line-deleted`), xanh dương cho chunk header (`diff-line-chunk`).
     - Chế độ Raw Unified: Hiển thị console code block tô màu cú pháp chuẩn git patch.
     - Trạng thái rõ ràng: Loading spinner (`diff-loading`), Error banner kèm retry (`diff-error`, `diff-retry-btn`), Empty state khi không có thay đổi (`diff-empty`).
  4. **Tích hợp vào `TaskDetail` (`apps/dashboard/src/components/TaskDetail.tsx`)**:
     - Bổ sung tab thứ 5 `Diff & Thay Đổi` (`tab-diff`) vào thanh sub-tabs của Run Inspector.
     - Hiển thị component `DiffViewer` trực tiếp với task ID hiện tại.
  5. **Tích hợp trang độc lập và route Next.js App Router**:
     - `apps/dashboard/src/app/tasks/[id]/diff/page.tsx`: Dynamic route `/tasks/:id/diff` xem diff của task kèm đường dẫn quay lại chi tiết task.
     - `apps/dashboard/src/app/diff/page.tsx`: Trang `/diff` hỗ trợ dropdown chọn task hoặc nhập mã task bất kỳ.
     - `apps/dashboard/src/app/page.tsx`: Thêm thẻ "🔍 Diff Viewer" (`card-diff`) trên trang chủ.
     - `apps/dashboard/src/index.ts`: Re-export `DiffViewer`.

### 3.1. Nghiệm thu qua Test Tích Hợp Hệ Thống Thực Tế (`test/ui-005.test.ts`)
Khởi tạo kho lưu trữ git thật (`git init -b main`), commit ban đầu, tạo thay đổi thật trên ổ đĩa, chạy backend Orchestrator Fastify và gọi client dashboard:

1. **Nghiệm thu 1: Xem diff thật — Lấy raw unified diff và metadata tập tin qua API `getTaskDiff`**
   - Sửa file `src/index.ts` trong repo git thật.
   - Gọi `api.getTaskDiff('TSK-UI-DIFF-1')`.
   - Kết quả: Nhận `rawDiff` thật chứa `diff --git a/src/index.ts b/src/index.ts`, `-  return "old world";`, `+  return "new world";`. Metadata file gồm status `modified`, `additions > 0`, `deletions > 0`, `inScope: true`, `isScopeClean: true`.
   - *Bằng chứng*: `test/ui-005.test.ts` (Nghiệm thu 1) — PASS.

2. **Nghiệm thu 2: Xem diff thật — Phát hiện file lạ ngoài scope (QLT-003) và đánh dấu rõ ràng**
   - Tạo thêm file lạ ngoài phạm vi `unauthorized_script.sh` trong repo git thật.
   - Sửa file trong scope `src/index.ts`.
   - Gọi `api.getTaskDiff('TSK-UI-DIFF-1')` và `api.getTaskScopeDiff('TSK-UI-DIFF-1')`.
   - Kết quả: Hệ thống xác định chính xác `isScopeClean: false`, `outOfScopeFiles: ['unauthorized_script.sh']`. Tập tin lạ được gán nhãn `inScope: false`, `stats.outOfScopeCount: 1`.
   - *Bằng chứng*: `test/ui-005.test.ts` (Nghiệm thu 2) — PASS.

3. **Nghiệm thu 3: Phân tích unified diff thành các dòng có loại (add/delete/chunk) và số dòng tương ứng**
   - Phân tích patch nội dung qua hàm `parsePatchLines`.
   - Kết quả: Bóc tách chính xác danh sách các dòng với loại `add`, `delete`, `chunk`, `header`, `context`. Dòng thêm có `newLineNumber`, dòng xóa có `oldLineNumber`, dòng chunk có tọa độ `@@`.
   - *Bằng chứng*: `test/ui-005.test.ts` (Nghiệm thu 3) — PASS.

4. **Nghiệm thu 4: API `getTaskDiff` xử lý chính xác khi không có thay đổi nào trong git (empty diff)**
   - Gọi API khi working tree sạch so với commit gốc.
   - Kết quả: `changedFiles: []`, `fileDiffs: []`, `rawDiff: ''`, `isScopeClean: true`, `stats.totalChanged: 0`.
   - *Bằng chứng*: `test/ui-005.test.ts` (Nghiệm thu 4) — PASS.

5. **Nghiệm thu 5: Gọi `compareScopeDiff` trực tiếp qua API POST `/api/quality/scope-diff`**
   - Truyền `{ repoPath, scopeFiles: ['src/index.ts'] }` qua client API.
