## 1. Kết Quả Thực Hiện

### 1.1. Data Model & Zod Schemas (`packages/shared/src/models/quality-review.ts`)
- **`ReviewFindingSchema`**: Xác thực bắt buộc 4 trường cốt lõi theo ROADMAP:
  - `severity`: enum `['info', 'low', 'medium', 'high', 'critical']`.
  - `file`: string (đường dẫn tương đối tới file, min 1).
  - `line`: số nguyên dương (line number >= 1).
  - `message`: string (nội dung thông báo lỗi/khuyến nghị, min 1).
  - Các trường làm giàu tùy chọn: `category`, `rule_id`, `suggestion`.
- **`ReviewFindingInputSchema`**: Tiền xử lý dữ liệu đầu vào linh hoạt từ LLM (chuẩn hóa viết hoa severity, ép kiểu line từ chuỗi/mặc định 1 nếu thiếu, ánh xạ `path`/`comment`).
- **`ReviewResultSchema` & `ReviewStatsSchema`**: Cấu trúc kết quả đánh giá gồm `passed`, `findings`, `stats` (phân loại số lượng theo từng mức severity), `summary`, `reviewed_at`, `reviewer_type`.
- **`extractJsonFindings(rawText)`**: Trích xuất JSON tin cậy từ phản hồi của AGY/LLM (hỗ trợ markdown code block ` ```json ... ``` `, mảng JSON `[...]`, object `{ findings: [...] }` hoặc `{ issues: [...] }`, tự động dọn trailing commas).
- **`isReviewPassing(findings)`**: Thực thi chính sách Quality Gate từ `SKILL-testing.md`: Trả về `false` nếu phát hiện bất kỳ finding nào có mức `high` hoặc `critical`.
- **`buildReviewerPrompt(options)`**: Khởi tạo prompt chuyên biệt cho Reviewer Agent kết hợp git diff, thay đổi file, mô tả task và tiêu chí nghiệm thu.

### 1.2. Migration 008 & Database Repository (`packages/db/migrations/008_review_findings.sql`)
- Khởi tạo bảng `review_findings` trong SQLite:
  - Cột: `id`, `task_id`, `run_id`, `severity`, `file`, `line`, `message`, `category`, `rule_id`, `suggestion`, `created_at`.
  - Khóa ngoại liên kết `tasks(id)` và `runs(id)` với `ON DELETE CASCADE`.
  - Chỉ mục tối ưu: `idx_review_findings_task_id`, `idx_review_findings_run_id`, `idx_review_findings_severity`, `idx_review_findings_file`, `idx_review_findings_created_at`.
- **`ReviewFindingRepository` (`packages/db/src/repositories/review-finding-repository.ts`)**:
  - `create(input)` & `createBatch(inputs)`: Thêm một hoặc nhiều findings trong transaction SQLite an toàn.
  - `findByTaskId(taskId)` & `findByRunId(runId)`: Truy vấn danh sách findings theo task hoặc run.
  - `find(filter)`: Lọc findings linh hoạt theo `severity`, `file`, `taskId`, `runId`, phân trang `limit`/`offset`.
  - `count(filter)`: Đếm số lượng findings theo điều kiện lọc.
  - Tự động lưu trữ báo cáo kiểm toán `review_findings` vào bảng `reports`.

### 1.3. Reviewer Service (`apps/orchestrator/src/services/reviewer-service.ts`)
- **`ReviewerService`**:
  - `reviewDiff(input)`: Tạo prompt kiểm thử, khởi chạy tiến trình AGY/Reviewer an toàn qua `ProcessAdapter.spawn` (không dùng shell động), giám sát timeout watchdog, thu thập stdout/stderr và chuyển đổi thành `ReviewResult`.
  - `reviewTask(taskId, options)`: Tự động tra cứu task từ SQLite, phân giải git diff thực tế của repository, kích hoạt quy trình review và lưu trữ kết quả.
  - `parseAndValidateReview(rawOutput, context)`: Bóc tách, xác thực qua Zod schema, tính toán thống kê và lưu bản ghi vào SQLite.

### 1.4. REST API Endpoints (`apps/orchestrator/src/routes/quality.ts`)
- `POST /api/quality/review`: Thực hiện review diff/prompt trực tiếp.
- `POST /api/quality/review/validate`: Xác thực và parse chuỗi output thô của reviewer không cần gọi tiến trình ngoài.
- `POST /api/tasks/:id/review`: Kích hoạt review cho task cụ thể.
- `GET /api/quality/findings`: Lọc và liệt kê danh sách findings (hỗ trợ query `severity`, `file`, `taskId`, `runId`, `limit`, `offset`).
- `GET /api/tasks/:id/review-findings`: Lấy danh sách findings gắn với task ID.
- `GET /api/runs/:id/review-findings`: Lấy danh sách findings gắn với run ID.
