## 1. Kết Quả Thực Hiện

### 1.1. Git Remote & Push Engine An Toàn (`packages/shared/src/git.ts`)
- **`gitPush(repoPath, options)`**:
  - Thực thi push an toàn qua `child_process.spawn('git', ['push', '-u', remote, branch])`, tuyệt đối không dùng shell injection hay cờ `--force`.
  - Quy tắc an toàn bắt buộc: Nghiêm cấm push trực tiếp lên các nhánh được bảo vệ (`main`, `master`), ném lỗi `AppError('FORBIDDEN_PUSH_BRANCH')` ngay lập tức.
  - Tự động kiểm tra và xác nhận remote branch qua `git ls-remote --heads <remote> <branch>` sau khi push (mặc định `confirm: true`).
  - Hỗ trợ cơ chế retry tự động với exponential backoff cho các lỗi mạng / kết nối tạm thời (`GIT_NETWORK_ERROR`, mặc định 2 lần thử lại).
- **`gitLsRemote(repoPath, options)` & `gitConfirmRemoteBranch(repoPath, branch, remote)`**:
  - Thực thi `git ls-remote --heads <remote> [branch]`, phân tích output định dạng `<commitSha>\t<ref>`.
  - Trả về cấu trúc `GitLsRemoteResult`: `{ branchFound, commitSha, ref, entries, raw }`.
  - Xác nhận branch và commit SHA tương ứng thực sự tồn tại trên remote repository.
- **`sanitizeGitOutput(text)`**:
  - Che giấu và loại bỏ toàn bộ token, credentials (`[REDACTED_CREDENTIALS]`, `[REDACTED_TOKEN]`) khỏi thông báo lỗi Git và log (GitHub PAT `ghp_*`, fine-grained `github_pat_*`, OAuth `gho_*`, Bearer tokens, URL credentials).
- **Phân loại lỗi Git (`classifyGitError`)**:
  - `GIT_AUTH_FAILED` (HTTP 401 / permission denied)
  - `GIT_REMOTE_NOT_FOUND` (remote URL / remote alias không tồn tại)
  - `GIT_NETWORK_ERROR` (DNS / connection timeout / network unreachable)
  - `GIT_NON_FAST_FORWARD` (push bị từ chối do xung đột lịch sử commit)
  - `GIT_REMOTE_BRANCH_NOT_FOUND` (không xác nhận được branch trên remote qua ls-remote)

### 1.2. Release Models & Schemas (`packages/shared/src/models/release.ts`)
- **`PushFeatureReleaseInputSchema`**: Tham số push release (`branch`, `remote`, `set_upstream`, `confirm_remote`, `repo_path`, `max_retries`, `retry_delay_ms`).
- **`PushFeatureReleaseResultSchema`**: Kết quả push gồm `release_id`, `feature_id`, `branch`, `remote`, `remote_ref`, `commit_sha` (40 chars hex), `status: 'PUSHED'`, `confirmed_remote: true`, `pushed_at`.
- **`ConfirmRemoteBranchInputSchema` & `ConfirmRemoteBranchResultSchema`**: Tham số và kết quả xác nhận remote branch.

### 1.3. FeatureReleaseService & FeatureService (`apps/orchestrator/src/services/`)
- **`pushFeatureRelease(featureId, input)`**:
  - Kiểm tra feature tồn tại (`FEATURE_NOT_FOUND`) và release record tồn tại (`FEATURE_BRANCH_NOT_FOUND`).
  - Đảm bảo branch đã được commit trước khi push (`FEATURE_NOT_COMMITTED` nếu chưa có commit SHA).
  - Tự động đảm bảo working tree ở đúng release branch trước khi commit release.
  - Gọi `gitPush` đẩy lên remote và xác nhận branch qua `git ls-remote`.
  - Cập nhật SQLite DB (`feature_releases`): chuyển trạng thái `status = 'PUSHED'`, lưu metadata `remote`, `remote_ref`, `remote_commit_sha`, `pushed_at`.
  - Ghi JSON structured log với thông tin release an toàn, không chứa secret.
- **`confirmRemoteBranch(featureId, input)`**: Kiểm tra trực tiếp trạng thái remote branch của feature qua `git ls-remote`.
- **Expose qua `FeatureService`**: Cung cấp `pushFeatureRelease` và `confirmRemoteBranch`.

### 1.4. REST API Endpoints & Server Integration (`apps/orchestrator/src/routes/features.ts`, `server.ts`)
- `POST /features/:id/push` & `POST /api/features/:id/push`: Push feature release lên remote, xác nhận branch và cập nhật DB (HTTP 200).
- `GET /features/:id/remote-status` & `GET /api/features/:id/remote-status`: Lấy trạng thái remote branch xác nhận qua `git ls-remote` (HTTP 200).
- Centralized Error Handling: xử lý `FORBIDDEN_PUSH_BRANCH` (400), `FEATURE_NOT_COMMITTED` (400), `GIT_AUTH_FAILED` (401), `GIT_REMOTE_NOT_FOUND` (404), `GIT_REMOTE_BRANCH_NOT_FOUND` (404), `GIT_NON_FAST_FORWARD` (409), `GIT_NETWORK_ERROR` (504), `GIT_PUSH_FAILED` (500).

## 2. Tiêu Chí Nghiệm Thu & Bằng Chứng

### Tiêu chí cốt lõi: `git ls-remote` thấy branch
- [x] **Nghiệm thu 1: `git ls-remote` thấy branch trên remote sau khi push**
  - Sau khi thực hiện `pushFeatureRelease`, lệnh `git ls-remote --heads origin feature/<feature-id>` trả về đúng branch với commit SHA trùng khớp chính xác 100% với commit SHA release trong DB.
  - *Bằng chứng*: `test/rel-005.test.ts` (Nghiệm thu 1) & `packages/shared/src/__tests__/git-push.test.ts`.
- [x] **Nghiệm thu 2: Lưu trạng thái PUSHED và metadata remote vào SQLite DB**
  - Bản ghi bảng `feature_releases` được cập nhật `status = 'PUSHED'`, lưu `remote: 'origin'`, `remote_ref: 'refs/heads/feature/...'`, `remote_commit_sha`, `confirmed_remote: true`.
  - *Bằng chứng*: `test/rel-005.test.ts` (Nghiệm thu 2).
- [x] **Nghiệm thu 3: Cấm push trực tiếp lên nhánh chính (main/master)**
  - Từ chối mọi yêu cầu push trực tiếp lên `main` hoặc `master` với mã lỗi `FORBIDDEN_PUSH_BRANCH` theo đúng quy định tại `SKILL-git-release.md`.
  - *Bằng chứng*: `test/rel-005.test.ts` (Nghiệm thu 3) & `packages/shared/src/__tests__/git-push.test.ts`.
- [x] **Nghiệm thu 4: Từ chối push khi feature release chưa được commit**
  - Nếu branch chưa được tạo commit (`release.commit_sha` null hoặc rỗng), hệ thống từ chối với lỗi `FEATURE_NOT_COMMITTED` (HTTP 400).
  - *Bằng chứng*: `test/rel-005.test.ts` (Nghiệm thu 4).
- [x] **Nghiệm thu 5: Bắt và báo lỗi GIT_REMOTE_NOT_FOUND khi remote không tồn tại**
  - Khi remote alias hoặc URL không tồn tại, trả về `GIT_REMOTE_NOT_FOUND` (HTTP 404).
  - *Bằng chứng*: `test/rel-005.test.ts` (Nghiệm thu 5) & `packages/shared/src/__tests__/git-push.test.ts`.
- [x] **Nghiệm thu 6: Che giấu token / bí mật khi gặp lỗi Git auth**
  - Hàm `sanitizeGitOutput` tự động lọc sạch các token PAT (`ghp_*`, `github_pat_*`), URL credentials và authorization secrets, không để lọt vào log hay lỗi trả về.
  - *Bằng chứng*: `test/rel-005.test.ts` (Nghiệm thu 6) & `packages/shared/src/__tests__/git-push.test.ts`.
- [x] **Nghiệm thu 7: Cơ chế tự động retry khi gặp lỗi mạng tạm thời**
  - Khi gặp lỗi mạng (`GIT_NETWORK_ERROR`, e.g. DNS resolve timeout), hệ thống tự động retry với backoff và hoàn thành khi kết nối hồi phục.
  - *Bằng chứng*: `test/rel-005.test.ts` (Nghiệm thu 7) & `packages/shared/src/__tests__/git-push.test.ts`.
- [x] **Nghiệm thu 8: REST API POST /features/:id/push và GET /features/:id/remote-status hoạt động chính xác**
  - Endpoint `POST /features/:id/push` trả về 200 kèm `status: 'PUSHED'`, `confirmed_remote: true`; `GET /features/:id/remote-status` xác nhận branch trên remote qua `git ls-remote`.
  - *Bằng chứng*: `test/rel-005.test.ts` (Nghiệm thu 8).
