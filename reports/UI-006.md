# Báo cáo nghiệm thu UI-006: Test report + review findings — Hiển thị bằng chứng

## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ theo ROADMAP.md**:
  - `UI-006`: Test report + review findings
  - **Dependencies**: `QLT-007` (DONE)
  - **Tiêu chí nghiệm thu**: `Hiển thị bằng chứng`
- **Các thành phần đã triển khai**:
  1. **API Client (`apps/dashboard/src/lib/api.ts`)**:
     - `getTaskQualityGateLatest(taskId)`: Lấy kết quả đánh giá Quality Gate gần nhất của task từ Orchestrator API (`GET /api/quality/gate/tasks/:id/latest`).
     - `getTaskQualityGateHistory(taskId)`: Lấy lịch sử các lần đánh giá Quality Gate của task (`GET /api/quality/gate/tasks/:id/history`).
     - `getQualityGateById(id)`: Lấy chi tiết bản ghi đánh giá Quality Gate theo ID (`GET /api/quality/gate/:id`).
     - `evaluateQualityGate(data)`: Gửi yêu cầu tính toán và lưu kết quả Quality Gate tùy biến (`POST /api/quality/gate/evaluate`).
     - `verifyTask(taskId, options)`: Kích hoạt quy trình kiểm định Quality Gate cho task và cập nhật trạng thái (`POST /api/tasks/:id/verify`).
     - `getTaskReviewFindings(taskId)` & `getRunReviewFindings(runId)`: Lấy danh sách vi phạm mã nguồn từ Reviewer Agent QLT-004.
     - `getTaskQualityRecords(taskId, query)` & `getRunQualityRecords(runId, query)`: Lấy dữ liệu thực thi chi tiết của từng lệnh kiểm thử test/lint/typecheck/build/security.
     - `getTaskSecurityChecks(taskId)`: Lấy bằng chứng quét lỗ hổng và secret scan theo QLT-005.
  2. **Component `TestReportReviewFindings` (`apps/dashboard/src/components/TestReportReviewFindings.tsx`)**:
     - **Thẻ tóm tắt Quality Gate (`evidence-summary-card`)**:
       - Huy hiệu trạng thái lớn: `✅ ĐẠT (PASSED)` (`gate-status-passed`) hoặc `❌ THẤT BẠI (FAILED)` (`gate-status-failed`).
       - Thông điệp tóm tắt và lý do đánh giá (`gate-summary-text`).
       - Thời gian thực thi (`gate-duration`) và thời điểm đánh giá (`gate-evaluated-at`).
       - Thanh chỉ số nhanh: Số lệnh pass/fail, tình trạng sạch scope, số review findings High/Critical, số secret và lỗ hổng audit.
     - **Banner cảnh báo quy trình QLT-007 (`cli-success-rejected-banner`)**:
       - Cảnh báo trực quan màu đỏ nổi bật: `⛔ CẢNH BÁO QUY TRÌNH: Không PASS chỉ vì CLI báo SUCCESS! Lệnh kiểm tra hoặc tiêu chuẩn Quality Gate thất bại.`
     - **Mục 1 — Bảng đánh giá quy tắc Quality Gate (`section-rule-evaluations`)**:
       - Hiển thị từng quy tắc: mã quy tắc (`rule_id`), tên quy tắc (`rule-name`), giai đoạn (`rule-stage`), huy hiệu trạng thái (`rule-status`), thông điệp chi tiết (`rule-message`).
     - **Mục 2 — Lệnh kiểm thử & Báo cáo Test (`section-quality-commands`)**:
       - Bộ lọc theo giai đoạn (Tất cả, Test, Lint, Typecheck, Build, Security, Custom).
       - Bộ lọc theo kết quả (Thành công Exit 0 vs Thất bại Non-zero).
       - Ô tìm kiếm lệnh theo từ khóa (`search-commands-input`).
       - Từng lệnh kiểm thử hiển thị mã thoát (`cmd-exit-code`), chuỗi lệnh (`cmd-string`), giai đoạn (`cmd-stage`), thời gian chạy (`cmd-duration`).
       - Nút chuyển đổi xem output (`cmd-toggle-output`): hiển thị toàn bộ log STDOUT (`cmd-stdout`) và STDERR (`cmd-stderr`) trong khung terminal monospace tối màu.
     - **Mục 3 — Đánh giá mã nguồn & Review Findings (`section-review-findings`)**:
       - Bộ nút lọc theo 5 mức độ nghiêm trọng: All, Critical, High, Medium, Low, Info (`filter-severity-*`) kèm số lượng.
       - Ô tìm kiếm file, thông điệp hoặc category (`search-findings-input`).
       - Từng finding hiển thị huy hiệu severity màu chuẩn, tọa độ `file:line` (`finding-file-line`), category (`finding-category`), rule ID (`finding-rule`), nội dung lỗi (`finding-message`), và hộp gợi ý khắc phục (`finding-suggestion`).
       - Hiển thị trạng thái sạch (`findings-empty-clean`): `✅ Không phát hiện vi phạm nào trong mã nguồn hoặc bộ lọc đã chọn!`.
     - **Mục 4 — Phạm vi & Bảo mật (`section-scope-security`)**:
       - Trạng thái kiểm tra phạm vi (QLT-003): Huy hiệu `SẠCH PHẠM VI` vs `PHÁT HIỆN FILE LẠ`, danh sách file lạ ngoài scope dạng pill tags (`evidence-scope-files`).
       - Trạng thái bảo mật (QLT-005): Huy hiệu `AN TOÀN BẢO MẬT` vs `CÓ LỖ HỔNG / SECRET`, số secret scan findings, số lỗ hổng audit High/Critical.
     - **Hành động & Điều khiển**:
       - Nút "Chạy Kiểm Định (Quality Gate)" (`btn-verify-task`): kích hoạt kiểm định trực tiếp qua REST API.
       - Nút "Làm mới" (`btn-refresh-evidence`): cập nhật lại dữ liệu.
       - Nút "Sao chép Markdown" (`btn-copy-markdown-report`): sao chép toàn bộ báo cáo kiểm toán chuẩn GFM vào clipboard.
       - Dropdown lịch sử kiểm định (`select-evaluation-history`): chuyển đổi giữa các lần đánh giá.
       - Các trạng thái rõ ràng: Loading spinner (`evidence-loading`), Error banner kèm retry (`evidence-error`, `btn-retry-evidence`), Empty state (`evidence-empty`, `btn-run-first-verify`).
  3. **Tích hợp vào `TaskDetail` (`apps/dashboard/src/components/TaskDetail.tsx`)**:
     - Bổ sung tab thứ 6 `🧪 Kiểm Định & Bằng Chứng` (`tab-quality`) vào thanh sub-tabs của Run Inspector.
     - Hiển thị trực tiếp component `TestReportReviewFindings` với task ID và run ID đang chọn.
  4. **Tích hợp trang độc lập và route Next.js App Router**:
     - `apps/dashboard/src/app/tasks/[id]/quality/page.tsx`: Route `/tasks/:id/quality` xem báo cáo kiểm thử và review findings kèm nút quay lại chi tiết task.
     - `apps/dashboard/src/app/quality/page.tsx`: Trang `/quality` hỗ trợ dropdown chọn task hoặc nhập mã task bất kỳ.
     - `apps/dashboard/src/app/page.tsx`: Thêm thẻ "🧪 Kiểm Định & Bằng Chứng (Quality Gate)" (`card-quality`) trên trang chủ.
     - `apps/dashboard/src/index.ts`: Re-export `TestReportReviewFindings`.
