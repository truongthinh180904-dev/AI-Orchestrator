## 2. Kết Quả Thực Hiện Chi Tiết

### 2.1. Backend Orchestrator API
1. **Truy vấn danh sách Release tập trung (`GET /releases` & `GET /api/releases`)**:
   - Thêm phương thức `listReleases(filter?)` trong `FeatureReleaseService` và `FeatureService`, truy vấn trực tiếp từ `FeatureReleaseRepository`.
   - Cung cấp Fastify route `GET /releases` và `GET /api/releases` với bộ lọc an toàn `feature_id` và `status` (`FeatureReleaseStatusSchema`).
   - Tái sử dụng các endpoints hiện hữu từ REL-001 → REL-006:
     - `GET /api/features/:id/release`: Lấy thông tin bản ghi release hiện tại.
     - `GET /api/features/:id/branch`: Lấy thông tin branch cục bộ.
     - `GET /api/features/:id/pr`: Lấy chi tiết Pull Request (URL, branch, SHA, pr_number).
     - `GET /api/features/:id/release-report`: Lấy nội dung báo cáo phát hành Markdown.
     - `POST /api/features/:id/release-check`: Kiểm tra điều kiện phát hành (readiness).
     - `POST /api/features/:id/pr`: Tạo Pull Request GitHub an toàn qua GitHub CLI.

### 2.2. Mở Rộng API Client (`apps/dashboard/src/lib/api.ts`)
Bổ sung đầy đủ các phương thức release vào `ApiClient`:
- `getReleases(filter?)`: Truy vấn danh sách release.
- `getFeatureRelease(featureId)`: Lấy thông tin release theo feature.
- `getFeatureBranch(featureId, repoPath?)`: Lấy thông tin branch.
- `getFeaturePr(featureId)`: Lấy thông tin Pull Request.
- `getFeatureReleaseReport(featureId)`: Lấy báo cáo phát hành Markdown.
- `getFeatureComponentTasks(featureId)`: Lấy danh sách task thành phần.
- `checkFeatureReleaseReadiness(featureId, options?)`: Kiểm tra tính sẵn sàng phát hành.
- `createFeatureBranch(featureId, options?)`: Tạo release branch an toàn.
- `commitFeatureRelease(featureId, options?)`: Tạo commit Conventional Commits và lưu SHA.
- `pushFeatureRelease(featureId, options?)`: Push release branch lên remote.
- `confirmRemoteBranch(featureId, options?)`: Kiểm tra remote branch qua `git ls-remote`.
- `createFeaturePr(featureId, options?)`: Tạo Pull Request GitHub.

### 2.3. Component Giao Diện Phát Hành `ReleaseDashboard` (`apps/dashboard/src/components/ReleaseDashboard.tsx`)
Triển khai giao diện toàn diện, trực quan, đáp ứng nghiêm ngặt tiêu chí nghiệm thu:
1. **Tiêu chí nghiệm thu cốt lõi (Hiện branch, SHA, PR URL)**:
   - **Branch**:
     - Hiển thị huy hiệu nhánh phát hành: `data-testid="release-branch-${id}"` với tên branch dạng `🌿 feature/FEAT-001`.
     - Hiển thị nhánh cơ sở (Base branch): badge code `main` hoặc `dev`.
   - **Commit SHA**:
     - Hiển thị short SHA 7 ký tự: `data-testid="release-sha-${id}"` với thẻ `<code>`.
     - Tooltip title chứa full SHA 40 ký tự hex.
     - Nút "Chép SHA" (`data-testid="btn-copy-sha-${id}"`): sao chép commit SHA vào clipboard kèm phản hồi tức thì ("✓ Đã chép").
     - Hiển thị "Chưa commit SHA" khi bản ghi chưa có SHA.
   - **PR URL**:
     - Thẻ liên kết ngoài: `data-testid="release-pr-link-${id}"` với `href={pr_url}`, `target="_blank"`, `rel="noreferrer"`.
     - Hiển thị số hiệu PR `#<pr_number>` nếu có và đường dẫn URL đầy đủ.
     - Nếu chưa tạo PR: hiển thị "Chưa tạo PR" (`data-testid="release-no-pr-${id}"`) và nút "+ Tạo PR" (`data-testid="btn-create-pr-row-${id}"`).

2. **Các tính năng vận hành bổ trợ**:
   - **Thống kê tổng quan (Metrics Grid)**:
     - Thẻ đếm: Tổng số releases, Chờ duyệt (`READY_FOR_REVIEW`), Đã tạo PR (`PR_CREATED`), Đã push remote (`PUSHED`), Đã hợp nhất (`MERGED`).
   - **Bộ lọc & Tìm kiếm**:
     - Dropdown lọc trạng thái: `ALL`, `READY_FOR_REVIEW`, `PR_CREATED`, `PUSHED`, `COMMITTED`, `BRANCH_CREATED`, `MERGED`, `CLOSED` (`data-testid="select-status-filter"`).
     - Ô tìm kiếm từ khóa (`data-testid="input-search-releases"`): tìm theo Feature ID, tên tính năng, branch, commit SHA.
   - **Báo cáo phát hành Markdown (`modal-release-report`)**:
     - Nút "📄 Báo Cáo" (`data-testid="btn-view-report-${id}"`) mở modal xem trước toàn văn báo cáo Markdown chuẩn từ `getFeatureReleaseReport`.
     - Hiển thị bảng component tasks, chất lượng Quality Gate, và checklist bàn giao.
   - **Thẩm định sẵn sàng phát hành (`modal-readiness-check`)**:
     - Nút "🔍 Kiểm Tra" (`data-testid="btn-check-readiness-${id}"`) gọi `checkFeatureReleaseReadiness`.
     - Hiển thị trạng thái "ĐỦ ĐIỀU KIỆN PHÁT HÀNH" vs "BỊ CHẶN PHÁT HÀNH", danh sách nguyên nhân chặn và chi tiết từng quy tắc.
   - **Tạo Pull Request (`modal-create-pr`)**:
     - Hộp thoại tạo PR trực tiếp: nhập tiêu đề, base branch, tùy chọn draft PR.
     - Tự động vô hiệu hóa nút submit (`isSubmittingPr`) khi đang gửi yêu cầu và hiển thị banner thông báo lỗi/thành công.
   - **Chất lượng trạng thái giao diện**:
     - Trạng thái Đang tải (`releases-loading`).
     - Trạng thái Rỗng (`releases-empty`).
     - Trạng thái Lỗi (`release-error-banner`) với nút Thử lại (`btn-refresh-releases`).
     - Tùy chọn Tự động làm mới (`checkbox-auto-refresh`).
