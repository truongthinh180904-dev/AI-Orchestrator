# Báo cáo nghiệm thu UI-004: Live logs (SSE) + thông báo — Cập nhật realtime

## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ theo ROADMAP.md**:
  - Xây dựng giao diện Live logs (SSE) và hệ thống thông báo realtime cho Next.js Dashboard:
    - Mở rộng `ApiClient` (`apps/dashboard/src/lib/api.ts`):
      - `getRunStreamUrl(runId, options)`: Tạo URL endpoint Server-Sent Events `/runs/:id/stream` hỗ trợ tham số `after_seq` và `live`.
      - `subscribeToRunStream(runId, handlers, options)`: Đăng ký nhận luồng sự kiện SSE từ Orchestrator API theo thời gian thực; hỗ trợ linh hoạt cả `EventSource` lẫn fallback streaming qua `fetch` (`ReadableStream` / line parser), tự động phân giải các sự kiện chuẩn (`stdout`, `stderr`, `process_start`, `process_exit`, `checkpoint`, `agent_output`, `result`, `parse_error`, `done`), hỗ trợ phục hồi luồng với `after_seq` / `Last-Event-ID`.
    - Component `LiveLogViewer` (`apps/dashboard/src/components/LiveLogViewer.tsx`):
      - Giao diện terminal console dark theme chuyên dụng cho hiển thị luồng log thời gian thực.
      - Thanh công cụ điều khiển (`live-log-toolbar`):
        - Huy hiệu Run ID (`live-run-id`).
        - Huy hiệu trạng thái kết nối trực tiếp (`live-status-badge`): Đang kết nối, Trực tuyến (LIVE), Hoàn thành (DONE), Mất kết nối, Lỗi.
        - Bộ đếm sự kiện thời gian thực (`live-event-count`): Hiển thị số dòng hiển thị / tổng số dòng nhận được.
        - Ô tìm kiếm lọc từ khóa theo thời gian thực (`input-log-search`).
        - Bộ chọn lọc loại sự kiện (`select-event-filter`): Tất cả, `stdout`, `stderr`, `checkpoint`, `process_start`, `process_exit`, `parse_error`, `ndjson`.
        - Nút bật/tắt tự động cuộn (`btn-toggle-autoscroll`, thuộc tính `data-autoscroll="true" | "false"`).
        - Nút xóa log màn hình (`btn-clear-logs`).
        - Nút tải file log (`btn-download-logs`): Xuất toàn bộ log định dạng văn bản `.txt`.
        - Nút kết nối lại thủ công (`btn-reconnect`).
      - Khối dòng log tuần tự (`live-terminal-container`): Đánh số thứ tự dòng `#seq`, thời gian microsecond, huy hiệu phân loại sự kiện màu sắc trực quan, và nội dung log / dữ liệu JSON.
      - Giới hạn kích thước bộ đệm trong bộ nhớ (`maxBufferSize`, mặc định 5000 dòng): Tự động cắt tỉa các sự kiện cũ nhất khi vượt ngưỡng để chống rò rỉ bộ nhớ trình duyệt.
    - Hệ thống Thông báo Realtime (`apps/dashboard/src/lib/notifications.ts` & `NotificationCenter.tsx`):
      - Quản lý trạng thái thông báo `NotificationStore` và hook phản ứng `useNotifications`.
      - Ánh xạ tự động sự kiện SSE vòng đời tiến trình (`createNotificationFromEvent`):
        - `process_start`: Cảnh báo Info thông báo tiến trình worker khởi động.
        - `checkpoint`: Cảnh báo Info thông báo đạt mốc kiểm thử / build.
        - `process_exit` (exitCode 0): Cảnh báo Success thông báo tiến trình hoàn thành thành công.
        - `process_exit` (exitCode != 0): Cảnh báo Error thông báo tiến trình thất bại kèm mã lỗi.
        - `parse_error`: Cảnh báo Warning cảnh báo dòng log không chuẩn cú pháp NDJSON.
        - `process_timeout`: Cảnh báo Error thông báo tiến trình bị ngắt do quá thời gian.
        - `process_stopped`: Cảnh báo Warning thông báo tiến trình bị hủy theo lệnh điều hành.
      - Thành phần giao diện Chuông thông báo (`NotificationBell`): Nút chuông trên Header, huy hiệu số lượng chưa đọc (`notification-badge-count`), menu thả xuống hiển thị danh sách, bộ lọc Tất cả / Chưa đọc, nút "Đọc tất cả", nút "Xóa hết".
      - Hộp thông báo nổi (`NotificationToastContainer`): Toast nổi ở góc dưới màn hình tự động biến mất hoặc có nút đóng thủ công.
    - Tích hợp vào `TaskDetail` (`apps/dashboard/src/components/TaskDetail.tsx`):
      - Bổ sung tab thứ 4 `Live Logs (SSE)` (`tab-live`) bên cạnh `Checkpoints`, `Báo cáo`, `Sự kiện & Logs`.
      - Khi chọn tab Live Logs, hiển thị trực tiếp `LiveLogViewer` kết nối với phiên chạy đang chọn.
    - Tích hợp vào Layout chung (`Header.tsx` và `DashboardLayout.tsx`):
      - Đặt `NotificationBell` trên thanh điều hướng đầu trang cạnh `ConnectionStatus`.
      - Đặt `NotificationToastContainer` ở cấp layout đảm bảo thông báo luôn nổi trên mọi trang.
- **Tiêu chí nghiệm thu theo ROADMAP.md**: `Cập nhật realtime`.

## 3. Bằng chứng nghiệm thu chi tiết

### Tiêu chí: Cập nhật realtime & Live logs (SSE) + thông báo

- [x] **Nghiệm thu 1: Live logs (SSE) — Máy chủ Orchestrator stream SSE qua endpoint GET /runs/:id/stream với định dạng chuẩn**
  - *Mô tả*: Khởi tạo Fastify server Orchestrator thật cùng SQLite database với seed run và chuỗi sự kiện tuần tự (`process_start`, `stdout`, `checkpoint`, `stderr`, `process_exit`). Gọi endpoint `GET /runs/:id/stream`, xác minh headers trả về đúng chuẩn SSE (`Content-Type: text/event-stream`, `Cache-Control: no-cache, no-transform`), nhận đầy đủ các sự kiện dạng `id: <seq>\nevent: <type>\ndata: <json>\n\n`, và nhận sự kiện kết thúc `event: done`.
  - *Bằng chứng*:
    - `test/ui-004.test.ts` ("Nghiệm thu 1: Live logs (SSE) — Máy chủ Orchestrator stream SSE qua endpoint GET /runs/:id/stream với định dạng chuẩn")
    - `apps/dashboard/src/__tests__/api.test.ts` ("getRunStreamUrl returns formatted SSE endpoint with options", "subscribeToRunStream connects via custom EventSourceClass and receives events")

- [x] **Nghiệm thu 2: Cập nhật realtime — ApiClient subscribeToRunStream nhận sự kiện thời gian thực**
  - *Mô tả*: Kết nối client `subscribeToRunStream` tới endpoint SSE thật của Orchestrator. Kiểm chứng callback `onEvent` nhận chính xác tuần tự 5 sự kiện theo thứ tự `seq` tăng dần không gián đoạn, chuyển đổi trạng thái kết nối tuần tự từ `connecting` qua `connected` đến `completed`, và kích hoạt callback `onDone` khi phiên chạy hoàn tất.
  - *Bằng chứng*:

  - *Bằng chứng*:

- [x] **Nghiệm thu 4: Thông báo (Notifications) — Tự động chuyển đổi sự kiện vòng đời và mốc checkpoint thành thông báo**
