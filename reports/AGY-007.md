# Báo cáo nghiệm thu AGY-007: Worker execution API: POST /runs, GET /runs/:id, GET /runs/:id/stream (SSE), POST /runs/:id/stop — Chạy thử qua API với CLI giả

## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ theo ROADMAP.md**:
  - Xây dựng hệ thống API điều khiển thực thi tiến trình worker cho Orchestrator:
    - `POST /runs`: Khởi chạy một lần chạy mới cho task với tham số lệnh tùy chỉnh hoặc mặc định từ task/config, kiểm tra ranh giới repository, lưu bản ghi vào bảng `runs` và ghi nhận sự kiện vào bảng `events`.
    - `GET /runs/:id`: Truy vấn thông tin chi tiết của một lần chạy (trạng thái, exit code, pid, started_at, finished_at, isRunning).
    - `GET /runs`: Liệt kê danh sách các lần chạy, hỗ trợ lọc theo `taskId` hoặc `status`.
    - `GET /runs/:id/stream`: Cung cấp luồng dữ liệu sự kiện thời gian thực qua Server-Sent Events (SSE) theo chuẩn HTTP (`text/event-stream`), hỗ trợ phát lại lịch sử sự kiện từ SQLite (`after_seq`/`Last-Event-ID`), gửi heartbeat định kỳ 15s, và đóng luồng khi tiến trình kết thúc.
    - `POST /runs/:id/stop`: Dừng một tiến trình worker đang thực thi theo yêu cầu (SIGTERM → grace period → SIGKILL), cập nhật trạng thái trong DB thành `CANCELLED`.
  - Giả lập AGY CLI bằng script mock Node.js (`fixtures/mock-agy-cli.cjs`) phát NDJSON events để kiểm thử tích hợp toàn diện qua API Fastify.
- **Tiêu chí nghiệm thu theo ROADMAP.md**: `Chạy thử qua API với CLI giả`.
