# Báo cáo nghiệm thu UI-002: Danh sách task/feature + bộ lọc — Dữ liệu từ API

## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ theo ROADMAP.md**:
  - Xây dựng giao diện Danh sách task/feature kèm bộ lọc cho Next.js Dashboard:
    - `TaskFeatureDashboard`: Component giao diện chính hiển thị danh sách nhiệm vụ (tasks) và tính năng (features) lấy dữ liệu thời gian thực từ Orchestrator API (`GET /api/tasks` và `GET /api/features`).
    - Tab chuyển đổi: Hỗ trợ 2 chế độ hiển thị: Tác Vụ (`tasks`) và Tính Năng (`features`), kèm huy hiệu đếm số lượng bản ghi tương ứng.
    - Thanh thống kê tóm tắt (Summary Metrics Bar): Hiển thị nhanh số lượng tác vụ và tính năng theo từng trạng thái (Tổng số, DONE, RUNNING/VERIFYING, READY, TODO, FAILED/BLOCKED).
    - Bộ lọc tác vụ (Task Filters):
      - Lọc theo trạng thái tác vụ (`TASK_STATUSES`: TODO, READY, RUNNING, VERIFYING, DONE, FAILED, BLOCKED, PAUSED, CANCELLED).
      - Lọc theo tính năng (`feature_id`) qua danh sách dropdown các feature đã tải từ API.
      - Lọc theo giai đoạn (`phase`) qua danh sách dropdown các phase của tác vụ.
      - Tìm kiếm từ khóa theo ID, tiêu đề, hoặc mô tả tác vụ (`search`).
    - Bộ lọc tính năng (Feature Filters):
      - Lọc theo trạng thái tính năng (`FEATURE_STATUSES`: TODO, IN_PROGRESS, DONE, FAILED, BLOCKED).
      - Tìm kiếm từ khóa theo ID, tên hoặc mô tả tính năng.
    - Trạng thái giao diện và tương tác:
      - Nút "Làm mới" (`btn-refresh`) để tải lại dữ liệu mới nhất từ API.
      - Nút "Xóa bộ lọc" (`btn-reset-filters`) để xóa mọi điều kiện lọc đang chọn.
      - Trạng thái nạp (`loading-indicator`) khi đang giao tiếp với backend API.
      - Trạng thái thông báo lỗi (`error-banner`) kèm nút "Thử lại" (`btn-retry`) khi kết nối API gián đoạn.
      - Trạng thái rỗng (`empty-tasks-state`, `empty-features-state`) khi không tìm thấy tác vụ hoặc tính năng khớp bộ lọc.
    - Bảng hiển thị tác vụ (`tasks-table`): Hiển thị Task ID (liên kết sang trang chi tiết), Tiêu đề & mô tả, Phase, Feature badge, Status badge, Lần chạy (`attempts / max_attempts`), Dependencies, và Ưu tiên.
    - Bảng hiển thị tính năng (`features-table`): Hiển thị Feature ID, Tên tính năng, Mô tả, Status badge, Danh sách task bắt buộc, và Integration test commands.
    - Component `StatusBadge`: Hiển thị huy hiệu trạng thái chuẩn hóa màu sắc và chỉ báo dot trực quan cho mọi trạng thái của Task và Feature.
    - Tích hợp trang App Router: Cập nhật `apps/dashboard/src/app/tasks/page.tsx` sử dụng component `TaskFeatureDashboard`.
- **Tiêu chí nghiệm thu theo ROADMAP.md**: `Dữ liệu từ API`.

- [x] **Nghiệm thu 2: Dữ liệu từ API — Lọc danh sách tác vụ theo status, phase, feature_id, và search query**
