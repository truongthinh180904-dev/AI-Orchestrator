# Báo cáo Nghiệm thu FND-004

## Thông tin Task
- **ID**: `FND-004`
- **Mô tả**: Logger JSON (timestamp, level, context) + `AppError`
- **Tiêu chuẩn nghiệm thu**: Test log đủ trường

## Các thành phần đã triển khai

1. **Lớp `AppError` (`packages/shared/src/errors.ts`)**:
   - Mở rộng từ lớp `Error` tiêu chuẩn.
   - Chứa 3 thuộc tính chính: `code: string`, `message: string`, `context: Record<string, unknown>`.
   - Phương thức `toJSON()` phục vụ xuất dữ liệu JSON an toàn kèm stack trace.
   - Các hàm tiện ích: `isAppError(error: unknown)`, `toAppError(error: unknown, fallbackCode)`.
   - Tích hợp vào `packages/db` qua workspace dependency `@ai-orchestrator/shared: "workspace:*"`, làm nguồn sự thật duy nhất cho mã lỗi toàn monorepo.

2. **Logger JSON (`packages/shared/src/logger.ts`)**:
   - Định dạng NDJSON (1 dòng JSON trên 1 log record kết thúc bằng `\n`).
   - Đảm bảo luôn đầy đủ 4 trường cốt lõi theo yêu cầu nghiệm thu:
     - `timestamp`: Chuỗi thời gian chuẩn ISO-8601 UTC.
     - `level`: Mức độ log (`debug`, `info`, `warn`, `error`).
     - `message`: Nội dung thông điệp dạng string.
     - `context`: Đối tượng metadata (mặc định `{}` nếu không truyền context).
   - Cơ chế che giấu dữ liệu nhạy cảm (tuân thủ nguyên tắc không log secrets):
     - Tự động thay thế giá trị các key nhạy cảm bằng `[REDACTED]` (không phân biệt hoa thường): `password`, `token`, `secret`, `apikey`, `api_key`, `authorization`, `auth`, `cookie`, `credential`, `private_key`, `access_token`, `refresh_token`.
     - Nhận diện và che giấu chuỗi Bearer token và API token dạng `sk-...`, `ghp_...` trong `message`, `context` và `stack`.
     - Bảo vệ chống crash đệ quy lặp vô tận bằng `WeakSet` (chuyển tham chiếu vòng thành `[CIRCULAR]`).
   - Hỗ trợ kế thừa context phân cấp: `logger.child(childContext)`.
   - Hỗ trợ dependency injection `destination` để test biệt lập.
   - Tự động bóc tách và định dạng an toàn cho đối số lỗi trong `logger.error(message, errorOrContext, context)`.

3. **Kiểm thử (`packages/shared/src/__tests__/` & `test/fnd-004.test.ts`)**:
   - `packages/shared/src/__tests__/errors.test.ts`: Kiểm tra khởi tạo, gán context, serialize `toJSON`, phân biệt type guards `isAppError`, `toAppError`.
   - `packages/shared/src/__tests__/logger.test.ts`:
     - Test nghiệm thu "Test log đủ trường (Nghiệm thu FND-004)" kiểm tra sự tồn tại và tính hợp lệ của cả 4 trường `timestamp`, `level`, `message`, `context`.
     - Kiểm tra context rỗng mặc định.
     - Kiểm tra lọc level log (debug, info, warn, error).
     - Kiểm tra che giấu secret trong context lồng nhau.
     - Kiểm tra che Bearer token trong message.
     - Kiểm tra format đối tượng `AppError` và `Error` trong log error.
     - Kiểm tra child logger và khả năng gộp context.
     - Kiểm tra phòng chống vòng lặp circular references.
   - `test/fnd-004.test.ts`: Kiểm thử tích hợp cấp độ root cho nghiệm thu FND-004.
