# Báo cáo Nghiệm thu FND-003

## Thông tin Task
- **ID**: `FND-003`
- **Mô tả**: `packages/db`: kết nối SQLite, runner migration có bảng `_migrations`, migration 001 (tasks, features, runs, events, reports)
- **Tiêu chuẩn nghiệm thu**: Chạy migration 2 lần không lỗi, có test

## Các thành phần đã triển khai
1. **Kết nối SQLite (`packages/db/src/connection.ts`)**:
   - Sử dụng thư viện `better-sqlite3`.
   - Cấu hình tự động các PRAGMA chuẩn theo `SKILL-sqlite.md`:
     - `PRAGMA journal_mode = WAL;` (bật WAL mode)
     - `PRAGMA foreign_keys = ON;` (bật ràng buộc khóa ngoại)
     - `PRAGMA busy_timeout = 5000;` (timeout 5s chống lock database)
2. **Runner Migration (`packages/db/src/migrator.ts`)**:
   - Tự động khởi tạo bảng `_migrations (id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL UNIQUE, applied_at TEXT NOT NULL)`.
   - Chạy từng file migration `.sql` theo thứ tự từ điển bên trong một SQLite transaction riêng biệt.
   - Idempotent: kiểm tra các migration đã áp dụng; nếu migration đã chạy thì bỏ qua. Chạy lại lần 2 không gây lỗi và trả về danh sách rỗng.
   - Tự động rollback transaction nếu có lỗi trong quá trình thực thi migration và ném `AppError` kèm context.
3. **Migration 001 (`packages/db/migrations/001_initial_schema.sql`)**:
   - Tạo đầy đủ các bảng cốt lõi:
     - `features` (id, name, description, required_tasks, integration_tests, release_policy, status, created_at, updated_at)
     - `tasks` (id, feature_id, title, description, phase, worker_type, repository, acceptance_criteria, test_commands, priority, max_attempts, timeout_minutes, status, attempts, created_at, updated_at)
     - `task_dependencies` (task_id, depends_on_id, PK(task_id, depends_on_id))
     - `runs` (id, task_id, attempt, status, exit_code, pid, started_at, finished_at, branch, commit_sha)
     - `events` (id AUTOINCREMENT, run_id, seq, type, payload, ts) kèm index `(run_id, seq)`
     - `reports` (id, run_id, kind, content, created_at) kèm index `(run_id)`
4. **Error handling (`packages/db/src/errors.ts`)**:
   - Lớp `AppError` chuẩn hóa theo quy tắc chung.
5. **Unit tests (`packages/db/src/__tests__/`)**:
   - `connection.test.ts`: Kiểm tra bật PRAGMAs foreign_keys, busy_timeout và WAL mode.
   - `migrator.test.ts`:
     - Test nghiệm thu: Chạy migration 2 lần không lỗi.
     - Kiểm tra tạo đầy đủ 6 bảng nghiệp vụ và bảng `_migrations`.
     - Kiểm tra ràng buộc khóa ngoại (foreign key enforcement) và cascade deletion / set null.
     - Kiểm tra rollback transaction khi migration gặp lỗi cú pháp.
     - Kiểm tra bắt lỗi khi thư mục migrations không tồn tại.
