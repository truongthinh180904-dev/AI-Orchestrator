# Báo cáo nghiệm thu TSK-007: UI chọn repo + preview import, nút Xác nhận/Hủy — Import được từ UI

## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ theo ROADMAP.md**:
  - Xây dựng giao diện Dashboard Next.js (App Router) cho quy trình Import tasks và features:
    - `RepoSelector`: Chọn repository đường dẫn (cwd) và nguồn dữ liệu (đường dẫn file Excel/CSV, tải file lên qua file upload, hoặc nhập trực tiếp chuỗi CSV).
    - `ImportPreview`: Xem trước chi tiết kết quả phân tích cú pháp và kiểm định hợp lệ (Validation Report, thống kê tổng số tasks, features, số lỗi, cảnh báo, bảng lỗi chi tiết, bảng xem trước danh sách tasks kèm dependencies và features).
    - `ImportWorkflow`: Điều phối quy trình xem trước (dry-run) và nút hành động:
      - Nút "Xem trước (Preview Import)": Gửi yêu cầu dry-run tới Orchestrator API (`POST /api/import`).
      - Nút "Xác nhận Nhập (Confirm Import)": Chỉ kích hoạt (`enabled`) khi dữ liệu hợp lệ (`valid: true`), gửi yêu cầu nạp chính thức (`POST /api/import` với `mode: 'commit'`), hiển thị thông báo thành công.
      - Nút "Hủy bỏ (Reset)": Đưa trạng thái xem trước và thông báo về ban đầu.
      - Xử lý trạng thái `isLoading` (vô hiệu hóa các nút điều khiển khi đang gọi API) và hiển thị banner thông báo lỗi chuẩn hóa từ API.
    - `ApiClient` (`apps/dashboard/src/lib/api.ts`): Client HTTP gọi Orchestrator API với base URL từ env `NEXT_PUBLIC_ORCH_URL` (hoặc mặc định `http://127.0.0.1:3000`), bóc tách lỗi thành `AppError`.
- **Tiêu chí nghiệm thu theo ROADMAP.md**: `Import được từ UI`.

## 3. Bằng chứng nghiệm thu chi tiết

### Tiêu chí: Import được từ UI

- [x] **Nghiệm thu 1: Luồng hoàn chỉnh từ UI — Preview file Excel hợp lệ, xác nhận không ghi DB khi dry-run**
  - *Mô tả*: Khởi tạo Fastify server orchestrator thật với SQLite in-memory, kết nối qua `ApiClient`. Người dùng chọn repository `.` và file mẫu `fixtures/sample-tasks.xlsx`, kích hoạt "Xem trước (Preview Import)". Hệ thống gửi `POST /api/import` ở chế độ dry-run, phản hồi `valid: true` kèm 13 tasks và 3 features. Xác minh trực tiếp vào SQLite rằng số lượng task trong DB vẫn bằng 0 (cam kết dry-run không ghi dữ liệu).
  - *Bằng chứng*:
    - `test/tsk-007.test.ts` ("Nghiệm thu: Luồng hoàn chỉnh từ UI — Preview file Excel hợp lệ, xác nhận không ghi DB khi dry-run")

- [x] **Nghiệm thu 2: Luồng hoàn chỉnh từ UI — Bấm Xác nhận Nhập (Commit) nạp thành công tasks và features vào DB**
  - *Mô tả*: Sau khi bản xem trước hợp lệ, nút "Xác nhận Nhập (Confirm Import)" được bật. Người dùng nhấn nút xác nhận, gửi yêu cầu commit tới API. Sau khi import thành công, UI gọi `api.getTasks()` và `api.getFeatures()` truy vấn lại dữ liệu từ server, kiểm tra các task và dependencies (như `TSK-001` phụ thuộc `FND-003`) đã được lưu đầy đủ vào DB SQLite.
  - *Bằng chứng*:
    - `test/tsk-007.test.ts` ("Nghiệm thu: Luồng hoàn chỉnh từ UI — Bấm Xác nhận Nhập (Commit) nạp thành công tasks và features vào DB")

- [x] **Nghiệm thu 3: Dữ liệu lỗi (trùng task_id) — UI preview hiển thị KHÔNG HỢP LỆ và từ chối commit**
  - *Mô tả*: Khi dữ liệu nguồn có lỗi trùng task_id, preview hiển thị trạng thái `KHÔNG HỢP LỆ (HAS ERRORS)`, hiển thị bảng lỗi chi tiết với mã `DUPLICATE_TASK_ID`. Nút "Xác nhận Nhập" bị vô hiệu hóa (`disabled: true`). Thao tác commit nếu bị gọi sẽ nhận lỗi `IMPORT_VALIDATION_FAILED` và DB giữ nguyên trạng thái không có bản ghi nào.
  - *Bằng chứng*:
    - `test/tsk-007.test.ts` ("Nghiệm thu: Dữ liệu lỗi (trùng task_id) — UI preview hiển thị KHÔNG HỢP LỆ và từ chối commit")
    - `apps/dashboard/src/__tests__/components.test.tsx` ("keeps confirm button disabled if preview has validation errors")

- [x] **Nghiệm thu 4: Dữ liệu chu trình (cycle) — UI preview hiển thị lỗi chu trình và không cho phép commit**
  - *Mô tả*: Khi dữ liệu chứa chu trình phụ thuộc vòng tròn, preview hiển thị thông báo lỗi `CIRCULAR_DEPENDENCY` kèm đường đi chu trình và ngăn chặn commit.
  - *Bằng chứng*:
    - `test/tsk-007.test.ts` ("Nghiệm thu: Dữ liệu chu trình (cycle) — UI preview hiển thị lỗi chu trình và không cho phép commit")
    - `apps/dashboard/src/__tests__/components.test.tsx` ("renders error list table when preview contains errors")

- [x] **Nghiệm thu 5: Upload file qua FormData từ UI — Preview và Commit thành công**
  - *Mô tả*: Hỗ trợ chế độ upload file trực tiếp từ máy tính (`fileUpload`) qua `FormData` multipart. API và UI xử lý phân tích và commit thành công.
  - *Bằng chứng*:
    - `test/tsk-007.test.ts` ("Nghiệm thu: Upload file qua FormData từ UI — Preview và Commit thành công")
    - `apps/dashboard/src/__tests__/api.test.ts` ("previewImport with File sends FormData")

- [x] **Nghiệm thu 6: Component controls — Nút Hủy (Reset), vô hiệu hóa khi đang gọi và hiển thị lỗi từ API**
  - *Mô tả*: Nút "Hủy bỏ (Reset)" xóa toàn bộ trạng thái preview và thông báo lỗi. Khi `isLoading: true`, các nút điều khiển tự động bị vô hiệu hóa để tránh race condition. Khi API trả về lỗi mạng hoặc HTTP error, UI hiển thị banner lỗi rõ ràng.
  - *Bằng chứng*:
    - `apps/dashboard/src/__tests__/components.test.tsx` ("handles cancel/reset button by clearing preview and states")
    - `apps/dashboard/src/__tests__/components.test.tsx` ("disables submit button and controls when isLoading is true")
    - `apps/dashboard/src/__tests__/components.test.tsx` ("displays error banner when preview API fails")
