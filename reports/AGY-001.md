## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ theo ROADMAP.md**:
  - Triển khai `ProcessAdapter` trong `apps/orchestrator/src/adapters/process-adapter.ts`:
    - `spawn(exe, args[])`: Tiếp nhận mảng tách biệt đối số, tuyệt đối cấm `shell: true`, cấm nối chuỗi lệnh từ input động.

  - Định nghĩa kiểu và schema validation `AgentCommand` và `ProcessExitResult` bằng `zod` trong `@ai-orchestrator/shared`.
- **Tiêu chí nghiệm thu theo ROADMAP.md**: `Không dùng shell; test với node -e`.

## 3. Bằng chứng nghiệm thu chi tiết

### Tiêu chí: Không dùng shell; test với node -e

- [x] **Nghiệm thu 1: spawn(exe, args[]) nhận mảng tách biệt và trả về ProcessHandle**
  - *Mô tả*: Khởi tạo tiến trình con với `exe: 'node'` và `args: ['-e', 'console.log("handle-ok")']`. Xác minh handle trả về có `pid > 0`, `startedAt` là `Date`, `stdout` và `stderr` là `Readable stream`, `isRunning()` là `true`. Đọc dữ liệu từ `stdout`, đợi `waitForExit()` trả về `{ exitCode: 0, signal: null, durationMs }` và `isRunning()` chuyển thành `false`.
  - *Bằng chứng*:
    - `test/agy-001.test.ts` ("nhận mảng tách biệt exe và args[], khởi tạo tiến trình và trả handle đầy đủ thuộc tính")
    - `apps/orchestrator/src/__tests__/process-adapter.test.ts` ("spawns a process with node -e, returns valid handle, and captures stdout")

- [x] **Nghiệm thu 2: Tuyệt đối không dùng shell (shell: false) — Chống command injection**
  - *Mô tả*:
    - Ngăn chặn command chaining: Truyền các đối số `['&&', 'echo', 'injected']` vào lệnh `node -e`. Do `shell: false`, ký tự `&&` không kích hoạt shell pipeline mà chỉ đóng vai trò đối số argv thường, lệnh phụ không bao giờ được thực thi.
    - Ngăn chặn nội suy biến: Truyền đối số `'$MY_SHELL_VAR'` vào `node -e`. Node nhận nguyên bản chuỗi `'$MY_SHELL_VAR'`, không bị shell thế giá trị biến môi trường.
    - Ngăn chặn file redirection: Truyền `['>', 'hacker_output.txt']`. File không hề được tạo trên đĩa do ký tự `>` không bị shell thông dịch.
  - *Bằng chứng*:
    - `test/agy-001.test.ts` ("không cho phép shell command chaining bằng toán tử && hoặc ;")
    - `test/agy-001.test.ts` ("không nội suy biến môi trường kiểu shell ($VAR)")
    - `test/agy-001.test.ts` ("không cho phép chuyển hướng file bằng toán tử shell redirection (>)")
    - `apps/orchestrator/src/__tests__/process-adapter.test.ts` ("passes arguments as an array directly without shell command chaining (&&)")
    - `apps/orchestrator/src/__tests__/process-adapter.test.ts` ("does not expand shell variables ($VAR)")
    - `apps/orchestrator/src/__tests__/process-adapter.test.ts` ("does not interpret shell redirection (>)")

- [x] **Nghiệm thu 3: Test với node -e (Đọc độc lập stdout, stderr, mã thoát và signal)**
  - *Mô tả*:
    - Ghi đồng thời ra stdout và stderr qua `process.stdout.write` và `process.stderr.write` trong `node -e`. Kiểm tra hai stream thu được nội dung chính xác và độc lập.
    - Kiểm tra bắt mã thoát lỗi khác 0 (`process.exit(77)` / `process.exit(42)`). `waitForExit()` thu được đúng `exitCode`.
    - Kiểm tra ngắt tiến trình bằng tín hiệu `SIGTERM` qua `handle.kill('SIGTERM')`. Tiến trình bị dừng, `signal === 'SIGTERM'`, và `isRunning()` trở thành `false`.
  - *Bằng chứng*:
    - `test/agy-001.test.ts` ("kiểm tra chạy lệnh thành công và đọc độc lập stdout và stderr")
    - `test/agy-001.test.ts` ("kiểm tra mã thoát khác 0 (non-zero exit code)")
    - `test/agy-001.test.ts` ("kiểm tra ngắt tiến trình đang chạy bằng tín hiệu SIGTERM")
    - `apps/orchestrator/src/__tests__/process-adapter.test.ts` ("captures stderr from node -e independently from stdout")
    - `apps/orchestrator/src/__tests__/process-adapter.test.ts` ("captures non-zero exit codes correctly")
    - `apps/orchestrator/src/__tests__/process-adapter.test.ts` ("terminates long-running process with handle.kill()")

- [x] **Nghiệm thu 4: Env whitelist an toàn (Lọc secret, không lộ token)**
  - *Mô tả*: Đặt biến nhạy cảm `TEST_SECRET_TOKEN` và `DB_PASSWORD` vào `process.env`. Chạy `node -e 'console.log(JSON.stringify(process.env))'`. Phân tích JSON trả về xác nhận các biến nhạy cảm hoàn toàn không xuất hiện trong tiến trình con, trong khi các biến an toàn trong whitelist (như `PATH`) được giữ nguyên. Kiểm tra khả năng nạp biến chủ đích qua `command.env` và `command.extraEnvWhitelist`.
  - *Bằng chứng*:
    - `test/agy-001.test.ts` ("loại bỏ triệt để biến môi trường nhạy cảm khỏi tiến trình con")
    - `test/agy-001.test.ts` ("cho phép nạp biến chủ đích qua command.env hoặc extraEnvWhitelist")
    - `apps/orchestrator/src/__tests__/process-adapter.test.ts` ("isolates process.env and filters unwhitelisted secrets")

- [x] **Nghiệm thu 5: Kiểm tra và từ chối cwd không hợp lệ**
  - *Mô tả*: Truyền `cwd` không tồn tại hoặc `cwd` là đường dẫn file. Hệ thống phát hiện ngay trước khi gọi `spawn` và ném `AppError` với mã lỗi `INVALID_WORKING_DIRECTORY`.
  - *Bằng chứng*:
    - `test/agy-001.test.ts` ("quăng lỗi AppError INVALID_WORKING_DIRECTORY khi cwd không tồn tại")
