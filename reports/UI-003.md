# Báo cáo nghiệm thu UI-003: Task detail + timeline — Lịch sử thật

## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ theo ROADMAP.md**:
  - Xây dựng giao diện Task detail + execution timeline cho Next.js Dashboard:
    - `TaskDetail`: Component giao diện chi tiết tác vụ hiển thị toàn diện metadata tác vụ và dòng thời gian thực thi các lần chạy kết nối trực tiếp với Orchestrator API (`GET /api/tasks/:id` và `GET /api/tasks/:id/history`).
    - Khối thông tin tác vụ (`task-info-card`):
      - Tiêu đề, Task ID, Huy hiệu trạng thái (`StatusBadge`), Phase, Feature badge.
      - Mô tả tác vụ đầy đủ (`task-description`).
      - Lưới chỉ số: Lần chạy (`attempts / max_attempts`), Mức ưu tiên (`priority`), Worker type, Repository, và Timeout.
      - Danh sách phụ thuộc (`task-dependencies`): Hiển thị các task phụ thuộc kèm liên kết chuyển hướng (`/tasks/:id`).
      - Tiêu chí nghiệm thu (`task-acceptance-criteria`): Danh sách checklist các tiêu chí cần đạt.
      - Lệnh kiểm thử (`task-test-commands`): Hiển thị các lệnh test dạng khối lệnh thực thi.
      - Phạm vi file (`task-scope-files`): Danh sách các file thuộc phạm vi tác vụ.
    - Dòng thời gian thực thi ("Lịch sử thật" — `task-run-timeline`):
      - Thanh tóm tắt tiến độ (`timeline-summary-bar`): Tổng số lần chạy, trạng thái lần chạy mới nhất, thời lượng, số checkpoints và báo cáo.
      - Danh sách thẻ lần chạy (`run-attempt-card-N`):
        - Hiển thị theo từng attempt: số thứ tự attempt, Run ID, trạng thái run, outcome (`SUCCESS`, `ERROR`, `TIMEOUT`), thời lượng thực thi, mã thoát (`exit_code`), mốc thời gian bắt đầu & kết thúc.
        - Thông tin Git: Nhánh feature (`branch`) và Commit SHA thu gọn.
        - Thông báo lỗi (`run-error-msg-N`) khi lần chạy thất bại.
        - Tương tác chọn hoặc chuyển đổi lần chạy để xem chi tiết sâu (`btn-inspect-run-N`).
    - Trình xem chi tiết sâu từng run ("Truy lại từng run" — `run-deep-inspector`):
      - Gọi API thật `GET /api/runs/:id/detail`.
      - Tab Checkpoints (`tab-checkpoints` / `run-checkpoints-timeline`): Hiển thị tuần tự các mốc thực thi (`run_started`, `compile_code`, `test_execution`, `run_completed`, `run_failed`) kèm trạng thái và payload JSON chi tiết.
      - Tab Báo cáo (`tab-reports` / `run-reports-list`): Hiển thị các báo cáo nghiệm thu, kiểm định chất lượng, test summary kèm nội dung và mốc thời gian.
      - Tab Sự kiện & Logs (`tab-events` / `run-events-breakdown`): Thống kê số lượng theo loại sự kiện (`eventStats`: stdout, stderr, agent_output, result) và danh sách luồng log có đánh số tuần tự.
    - Trạng thái giao diện:
      - Trạng thái nạp (`loading-task-detail`) khi đang truy vấn API.
      - Trạng thái lỗi (`task-error-banner`) kèm nút "Thử lại" (`btn-retry-task`) và nút quay lại danh sách.
      - Trạng thái rỗng (`empty-timeline-state`) khi task chưa từng được điều phối chạy (0 attempts).
      - Nút "Làm mới" (`btn-refresh-task`) trên thanh tiêu đề để tải lại toàn bộ trạng thái mới nhất.
    - Mở rộng `ApiClient` (`apps/dashboard/src/lib/api.ts`):
      - `getTaskHistory(id)`: Lấy lịch sử các lần chạy đa attempt.
      - `getRunDetail(id)`: Truy lại thông tin chi tiết của một run.
      - `getTaskCheckpoints(id, filter)`: Lấy danh sách checkpoints của task.
      - `getRunReports(runId, filter)`: Lấy danh sách reports của run.
    - Tích hợp trang App Router: Tạo trang `apps/dashboard/src/app/tasks/[id]/page.tsx` hỗ trợ cả Promise params và object params.
- **Tiêu chí nghiệm thu theo ROADMAP.md**: `Lịch sử thật`.
