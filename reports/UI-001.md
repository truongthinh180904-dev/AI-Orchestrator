# Báo cáo nghiệm thu UI-001: Layout + navigation — Chạy local

## 1. Mục tiêu và Tiêu chí nghiệm thu
- **Nhiệm vụ theo ROADMAP.md**:
  - Xây dựng Layout tổng thể và Navigation cho giao diện Dashboard Next.js (App Router) phục vụ giám sát và điều phối tác vụ worker:
    - `Header`: Hiển thị thương hiệu AI Orchestrator, huy hiệu phiên bản monorepo (`v0.1.0`), tiêu đề phụ, và huy hiệu trạng thái kết nối backend API thời gian thực (`ConnectionStatus`).
    - `ConnectionStatus`: Tích hợp với `ApiClient` gọi `GET /api/health`, tự động hiển thị trạng thái API trực tuyến (Connected - xanh lá), mất kết nối (Disconnected - đỏ), hoặc đang kiểm tra, kèm địa chỉ base URL của Orchestrator và nút bấm làm mới kiểm tra thủ công.
    - `Navigation`: Thanh điều hướng các phân hệ cốt lõi theo ROADMAP:
      - Tác vụ (`/tasks`, `/`): Danh sách và tiến độ các tác vụ worker.
      - Nhập Yêu Cầu (`/import`): Nạp task từ file Excel hoặc CSV (tích hợp `ImportWorkflow` từ TSK-007).
      - Điều Khiển (`/controls`): Bảng điều khiển Pause/Resume/Stop (sẵn sàng cho UI-007).
      - Phát Hành & PR (`/releases`): Quản lý branch release và Pull Requests (sẵn sàng cho UI-008).
      - Hỗ trợ đánh dấu active route thông minh qua `aria-current="page"` và `data-active`.
    - `Footer`: Chân trang hiển thị thông tin monorepo (`apps/orchestrator: 3000`, `apps/dashboard: 3001`, `packages/shared`, `packages/db`), huy hiệu chế độ hoạt động (`Chế độ: Headless Autonomous`), và nguyên tắc xác minh Quality Gate.
    - `DashboardLayout`: Wrapper component chuẩn hóa bọc Header, Navigation, container `main` và Footer cho toàn bộ ứng dụng.
    - Next.js App Router Pages: Cấu hình `RootLayout` (`apps/dashboard/src/app/layout.tsx`) tự động bọc mọi trang con với `DashboardLayout`, cung cấp các trang `/` (Dashboard Overview với các card phân hệ), `/tasks`, `/import`, `/controls`, `/releases`.
    - Hỗ trợ chạy local: Cấu hình scripts `"dev": "next dev -p 3001"` và `"start": "next start -p 3001"` trong `apps/dashboard/package.json` và cấu hình `next.config.mjs` tối ưu hóa cho monorepo.
- **Tiêu chí nghiệm thu theo ROADMAP.md**: `Chạy local`.
